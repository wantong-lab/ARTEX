# 出口代理池页面布局优化

## 背景

当前 /function/proxy-pool 把录入、兜底、Clash 订阅、直接导入、代理列表按单列堆叠，主次不清；Clash 订阅和“直接导入”各有一个订阅 URL 输入框，视觉重复。

## 目标

- 主流程优先：Clash 订阅代理是主入口，放在首屏；
- 手工录入/兜底代理作为辅助操作；
- 直接导入降为高级折叠项，不再重复订阅 URL；
- 列表占满宽度，空态更紧凑；
- 保留现有 API/行为，不改后端。

## 布局

- 页面标题/状态保持右上角；
- 第一块：Clash 订阅代理卡片（状态、mihomo、URL、启动/刷新/停止）；
- 第二块：手工录入 + 兜底代理两列；
- 第三块：折叠的“直接导入 http/socks5 节点”；
- 第四块：代理池列表全宽；
- 窄屏单列，宽屏两列。

## 兼容

- 所有按钮/API 不变；仅调整 JSX 顺序与折叠；
- 直接导入只保留 YAML 粘贴，不再放第二个订阅 URL 输入。

## 测试

- web build；
- 页面加载、启动/刷新/停止、手工录入、导入、列表操作手动验证。
